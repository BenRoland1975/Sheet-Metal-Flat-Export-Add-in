Copy the following SolidWorks Interop DLLs to this folder:

- SolidWorks.Interop.sldworks.dll
- SolidWorks.Interop.swconst.dll
- SolidWorks.Interop.swpublished.dll

You can find these files in your SolidWorks installation folder, typically at:
C:\Program Files\SOLIDWORKS Corp\SOLIDWORKS\api\redist

These references are needed to build the add-in.
